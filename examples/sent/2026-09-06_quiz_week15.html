Question 4 · Day 86 · Multimodal Models
When a multimodal model processes an image and a text caption together, which architectural component typically merges the two modalities?
A. Cross‑modal attention layer
B. Convolutional encoder
C. Positional embedding
D. Dropout layer

Answers

Q1: Model overfitting
Overfitting is a training‑time issue, while the other options are common problems that arise during production.
Q2: Identify the operating system and browser to the server
The User-Agent informs the server about the client’s software so it can tailor responses or perform content negotiation.
Q3: Reinforcement Learning from Human Feedback (RLHF)
Anthropic relies on RLHF to fine‑tune agents toward helpfulness, safety, and alignment with user goals.
Q4: Cross‑modal attention layer
Cross‑modal attention allows the model to jointly attend to visual and textual features, creating an integrated representation.
