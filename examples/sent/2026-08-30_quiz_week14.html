Question 4 · Day 80 · Guardrails and Safety Layers
In a multi-layer safety architecture, what is the primary purpose of a post-generation classifier?
A. To rewrite unsafe tokens before generation
B. To filter out completions that violate policy after they are produced
C. To rank candidate completions during beam search
D. To enforce token-level probability thresholds

Answers

Q1: Built-in replication and sharding
Replication and sharding let the system distribute queries across nodes, keeping latency low as data grows.
Q2: Field validators
Field validators run when the model is instantiated, enforcing type and value constraints so the resulting output matches the schema.
Q3: Using a system prompt that prefixes user input
A fixed system prompt isolates user content, making it harder for injected text to change the model's intended behavior.
Q4: To filter out completions that violate policy after they are produced
The post-generation classifier examines the finished output and blocks any response that breaches safety policies.
