Day 84: Hosting LLMs – API vs Self-hosted (vLLM, TGI)
TL;DR
Learn when running an LLM yourself saves money and how to compute throughput‑cost trade‑offs.

In plain English

Using a hosted API is like borrowing a car: you pay per mile and never worry about maintenance, but the per‑mile price can add up if you drive a lot. Self‑hosting an LLM with frameworks like vLLM or Text Generation Inference (TGI) is like owning a car; you pay upfront for the vehicle and fuel, and you control how fast you can go.
The decision hinges on two numbers: the expected request volume (tokens per day) and the throughput you can achieve on your hardware (tokens per second per GPU). By converting both options to a daily cost, you can see the break‑even point where self‑hosting becomes cheaper than the API. The math is simple multiplication and division, but it reveals whether you need to invest in GPUs, network bandwidth, and observability tooling.
If your workload spikes, self‑hosting also lets you scale horizontally, but you must budget for idle capacity, monitoring, and possible fine‑tuning pipelines. An API shields you from these ops headaches at a higher per‑token price.

Think of it this way

Think of a restaurant: ordering takeout from a popular chain (API) costs a premium per dish, while opening your own kitchen (self‑host) requires buying appliances and hiring staff, but once set up each meal costs only the raw ingredients.

In code

api_price = 0.0002  # $ per 1k tokens
tokens_per_req = 1500
req_per_day = 5000
api_cost = api_price * tokens_per_req/1000 * req_per_day

gpu_hour_cost = 3.0
tokens_per_sec = 12000  # tokens per second per GPU
seconds_per_day = 86400
gpu_needed = (tokens_per_req * req_per_day) / (tokens_per_sec * seconds_per_day)
self_cost = gpu_needed * gpu_hour_cost * 24
print(f"API: ${api_cost:.2f} vs Self-host: ${self_cost:.2f}")
The snippet converts per‑token API pricing and per‑GPU throughput into a daily cost for each option, then prints the comparison.

Why it matters for AI Eng interviews

Hiring managers look for engineers who can size infrastructure for RAG pipelines, autonomous agents, and large‑scale evals, balancing fine‑tuning compute against observability and MCP (model‑control‑plane) costs; knowing the break‑even math lets you argue for the right deployment strategy and keep production budgets in check.
One thing to remember
Self‑hosting only beats an API when your token volume and throughput justify the upfront GPU and ops spend.
