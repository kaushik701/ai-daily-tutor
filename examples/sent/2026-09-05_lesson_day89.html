Day 89: Production Failure Modes
TL;DR
Learn to detect and mitigate hallucination, drift, cost spikes, and latency tails in AI services.

In plain English

In production, a model can start *hallucinating*—producing outputs that look plausible but have no grounding in the input or knowledge base. This often shows up in Retrieval‑Augmented Generation (RAG) pipelines when the retriever returns irrelevant documents.\n\n*Drift* occurs when the data the model sees in the wild slowly diverges from the training distribution, causing accuracy to decay over time. Simultaneously, hidden cost spikes can appear when a new query pattern triggers a much larger model or longer context, inflating cloud spend. Finally, *latency tails* are rare but severe delays that break SLAs and hurt user experience, especially for real‑time agents and evaluation loops.

Think of it this way

Think of a restaurant kitchen: if the chef starts guessing ingredients (hallucination), the menu changes without notice (drift), the gas bill suddenly jumps (cost spike), and occasional orders take forever to cook (latency tail), the dining experience collapses unless the manager monitors and corrects each issue.

In code

import time, random, statistics, logging\n\nthreshold = 0.5  # seconds\nwindow = []\nwhile True:\n    latency = random.random()  # replace with real call timing\n    window.append(latency)\n    if len(window) > 100:\n        window.pop(0)\n        p95 = statistics.quantiles(window, n=100)[94]  # 95th percentile\n        if p95 > threshold:\n            logging.warning(f"Latency tail detected: p95={p95:.3f}s")\n    time.sleep(0.1)
The snippet keeps a sliding window of recent latencies and logs a warning when the 95th‑percentile exceeds a safety threshold, a common pattern for spotting latency tails.

Why it matters for AI Eng interviews

Employers look for engineers who can keep RAG pipelines reliable, monitor agent response times, run continuous evals, and trigger fine‑tuning when drift is detected—all while maintaining observability and cost control on the Model Control Plane (MCP). An on‑call mindset that anticipates hallucination, drift, cost spikes, and latency tails demonstrates readiness for production AI responsibilities.
One thing to remember
Always instrument the 95th‑percentile latency and set alerts before a tail hurts your SLA.
